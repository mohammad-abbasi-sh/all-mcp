قدم ۱ از ۳ — هم‌صحبتت رو انتخاب کن

کی باهات حرف بزنه؟

هر شخصیت لحن و حال‌وهوای خودش رو داره — مثل یه دوست که راهنماییت می‌کنه. هر وقت خواستی عوضش کن.

قدم ۲ از ۳ — کجا زندگی می‌کنی؟

کشورت رو انتخاب کن

وقتی توی سؤالت اسم شهر نیست، چت سراغ سرویس‌های کشور خودت می‌ره. هر وقت خواستی از بالای صفحه عوضش کن.

قدم ۳ از ۳ — تقریباً تمومه

اسمت چیه؟ (اختیاری)

اسمت فقط توی مرورگر خودت می‌مونه — هیچ‌جا فرستاده نمی‌شه. چت باهاش صمیمی‌تر حرف می‌زنه.

حافظهٔ چت (نام، کشور، زبان، تاریخچه) فقط در مرورگر تو ذخیره می‌شود — بدون حساب کاربری، بدون سرور.

سرور محلی وصل نیست

چت با سرور all-mcp روی خودِ کامپیوترت حرف می‌زنه — هیچ داده‌ای به سرور ما نمی‌رسه. برای راه‌انداختنش ۳۰ ثانیه کافیه:

  1. نصب uv (یک بار):
    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. سرور رو اجرا کن:
    uvx all-mcp --http --port 8765
  3. بعد دکمهٔ «بررسی دوباره» رو بزن — همین.

نکته: برای جواب یک‌مرحله‌ای با هوش مصنوعی، یه کلید API (مثلاً GEMINI_API_KEY) رو توی محیط سرورت بذار — کلید هرگز از کامپیوترت بیرون نمی‌ره. بدون کلید هم چت کار می‌کنه.

سلام! 👋

همه‌چیز روی کامپیوتر خودت اجرا می‌شه — بدون حساب، بدون ردیابی.
